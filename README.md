# Portfolio Template — Grade 2

## Project Overview

This project is a portfolio template developed as part of the Web Atelier course.  
The goal was to design and build a responsive, modern portfolio using **HTML, CSS, Bootstrap, and GSAP**, with a strong focus on **layout, structure, and visual hierarchy** rather than heavy visual decoration.

The project reflects my background in graphic design and my interest in translating editorial and grid-based design principles into the web.

---

## Design Concept

The visual language of this portfolio is **modern, minimal, and typographically driven**.  
Instead of relying on decorative elements, the design is built around:

- Clear grid systems
- Strong alignment and spacing
- Large-scale typography
- Blocks of color used as structural elements

The layout is intentionally restrained so that hierarchy, rhythm, and composition do most of the visual work.

---

## Layout & Grid System

The entire website is structured using **Bootstrap’s grid system**, which allowed me to experiment with:

- Asymmetrical layouts
- Offset columns
- Negative space as a design element
- Full-width sections combined with constrained content

Rather than using the grid only for responsiveness, I treated it as a **design tool**, similar to how grids are used in editorial design. Different sections intentionally shift alignment to create contrast and visual interest while maintaining consistency.

---

## Typography

Typography plays a central role in the project.

- Large, fluid headings are used to establish hierarchy
- Text scales responsively using `clamp()` to adapt smoothly across screen sizes
- Line height, spacing, and alignment are carefully controlled to maintain readability and balance

The typographic system is designed to feel bold but controlled, prioritizing clarity over decoration.

---

## Color System & Dark Mode Decision

The project uses a **single, consistent color system**.

I intentionally chose **not to implement a dark mode**. This decision was based on the concept of the project rather than a technical limitation:

- The visual identity relies on contrast created through layout, spacing, and blocks — not through theme switching
- A light interface supports the editorial, print-inspired aesthetic of the design
- Introducing dark mode would have duplicated the same layouts without adding meaningful value to the concept

Instead of offering two visual modes, I focused on refining **one clear visual direction**.

---

## Animations & Interaction

Animations are used sparingly and with intention.

- Text and project cards reveal on scroll using GSAP
- Animations reinforce hierarchy (titles appear before supporting text)
- Movement is subtle and vertical, avoiding distracting effects
- Reduced motion preferences are respected

The goal of the animations is to **support the content and structure**, not to dominate the experience.

---

## Responsiveness

The project follows a **mobile-first approach** with progressive enhancement:

- Bootstrap responsive columns adapt layouts across breakpoints
- Images adjust their behavior on smaller screens to avoid excessive cropping
- Typography scales fluidly with viewport size

Special attention was given to ensuring the design remains clear and readable on smaller devices without losing its graphic character.

---

## 404 Page

A custom 404 page was designed to match the overall visual language of the site.

Rather than treating it as a separate page, the 404 behaves like an extension of the portfolio:

- Same typography
- Same grid logic
- Simple entrance animation to maintain consistency

---

## AI Usage

Artificial Intelligence was used **as a support tool**, not as a replacement for design or decision-making.

AI was mainly used for:

- Clarifying technical concepts (GSAP, ScrollTrigger, responsive typography)
- Debugging specific animation or layout issues
- Helping structure planning and documentation

All design decisions, layout choices, and visual direction were made by me.  
AI assisted in translating ideas into code and understanding complex interactions, especially related to animations.

---

## Conclusion

This project represents my approach to web design as an extension of graphic design:  
clear systems, intentional layouts, and visuals that communicate through structure.

Rather than focusing on feature quantity, the project prioritizes **coherence, hierarchy, and refinement**.
